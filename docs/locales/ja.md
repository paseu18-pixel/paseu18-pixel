# マテオ・シルバ＝カルヴァーリョ (Mateo Silva-Carvalho)

**分散ストレージ＆データベース内部構造エンジニア | システム職人**  
*ブラジル・フロリアノーポリス | UTC-3*

> *「ディスクI/Oは犯行現場であり、書き込み増幅（Write Amplification）は犯人です。そしてB-TreeとLSM-Treeこそが決定的な証拠です。」*

高スループットなデータベースストレージエンジン、追記専用（Append-only）先行書き込みログ（WAL）、分散合意インフラストラクチャの設計と実装を手掛けています。日々、低レベルLinuxシステムプログラミング、カーネルバイパス非同期I/O（`io_uring`）、メモリマップト永続データ構造、そしてモダンなGo、C++20、Zigによるロックフリー並行ページキャッシュの実装に専念しています。

ターミナルを離れたときは、ブラジル産シングルオリジンのスペシャルティコーヒー（カトゥアイ、イエローブルボン）の自家焙煎、サンタカタリーナ海岸の大西洋でのウインドサーフィン、自作分割型エルゴノミクスメカニカルキーボードの手半田付け組み立てを楽しんでいます。

## 専門領域と主な取り組み

- **データベースストレージエンジン**: レベルド（Leveled）および階層型（Tiered）LSM（Log-Structured Merge）ツリーの設計、適応型グループコミットによるゼロアロケーションWAL、ブロックキャッシュ追放アルゴリズム（W-TinyLFU、2Q、Clock-Pro）の実装。
- **非同期ストレージ＆カーネルバイパス**: 事前登録固定バッファ（`IORING_REGISTER_BUFFERS`）、ゼロコピーソケットスプライシング（`splice`）、アライメント済みダイレクトブロック転送（`O_DIRECT`）を用いたLinux `io_uring`によるNVMe SSD帯域の極限飽和。
- **分散合意システム**: Multi-Raftステートマシン、ベクトルクロックログコンパクション、ネットワーク分断・フォールトインジェクションシミュレーションによる決定論的クラッシュリカバリ検証。
- **キャッシュ効率の高い並行データ構造**: ロックフリースキップリスト、キャッシュライン整列型Adaptive Radix Tree（ART）、適応型プレフィックスB+Tree、メモリ安全なアリーナアロケータの開発。

## 主要オープンソースプロジェクト

### [ouroboros-kv](https://github.com/mateo-silva/ouroboros-kv)
*ゼロアロケーション読み取りパスを備えたGo製組み込み型ロックフリーLSMストレージエンジン。*
- キャッシュライン整列ノードを持つロックフリースキップリストベースの並行メンテーブル（Memtable）を実装。
- NVMeの書き込み増幅（Write Amplification）を最小化する適応型階層コンパクションを搭載。
- ヒープアロケーションなしで偽陽性率を0.8%未満に抑えるブロック型SIMDブルームフィルタを採用。
- crc32cチェックサム検証とベクトルブロックフラッシュを備えた追記専用WALによるクラッシュリカバリ。

### [ring-fs](https://github.com/mateo-silva/ring-fs)
*ネイティブ`io_uring`を活用しZigで構築された高性能ユーザ空間追記専用ストレージエンジン。*
- 登録済み固定バッファ（`IORING_REGISTER_BUFFERS`）と専用カーネル送信ポーラー（SQPOLL）スレッドのみで動作。
- コンシューマ向けPCIe 4.0 NVMe環境において、持続シーケンシャル書き込み820,000 IOPS以上を達成。
- 予測可能な4KBページアライメントとハードウェア直結ゼロコピーシリアライズを備えたユーザ空間ページキャッシュマネージャ。

### [paxos-forge](https://github.com/mateo-silva/paxos-forge)
*分散合意ステートマシンのための決定論的シミュレーションハーネス。*
- 仮想的な非同期ネットワーク分断、メッセージ消失、ランダムなクロックドリフト環境下でログ複製エンジンを検証。
- 単一プロセス内で仮想離散時間をステップ単位で制御し、数千の仮想ノードによるバグ再現を可能に。
- 複数のRaftおよびMulti-Paxos参照実装における状態遷移を厳密に検証済み。

### [vfs-spdk](https://github.com/mateo-silva/vfs-spdk)
*SQLiteクエリをNVMe SSDへ直接ルーティングする実験的カスタム仮想ファイルシステム（VFS）ドライバ。*
- SPDKユーザ空間NVMeドライバを介してブロック範囲へ直接書き込み、OSファイルシステム層をバイパス。
- 高頻度トランザクションワークロードにおいて、p99コミットレイテンシを42%短縮。

## ストレージエンジンの不変則（行動規範）

低レベルストレージルーチンを記述する際、以下の4つの原則を厳格に順守しています：

```
[ストレージエンジンの機械的不変則]
├── 1. 永続性（Durability）は妥協不可
│   └── fsync / fdatasync バリアが完了するまで、同期クライアントへ成功を返してはならない。
├── 2. メモリ＆キャッシュラインアライメントの徹底
│   └── ディスク上のすべてのページ構造体は、4096バイト境界に厳格に整列させる（O_DIRECT安全）。
├── 3. ホットパスにおけるロック競合の完全排除
│   └── 読み取りおよび追記パスは、アトミックCASとシーケンスポインタにより完全なロックフリーを維持する。
└── 4. 極限の障害テストによる証明
    └── 突然のカーネルパニックや電源喪失テストに耐えられないストレージは、動作しているとは言えない。
```
